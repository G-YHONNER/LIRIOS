# 🌸 LIRIOS - Para ti, Dianna Marisol 🌸

Un jardín interactivo animado con flores brillantes y luciérnagas mágicas bajo un cielo estrellado.

## ✨ Características
- 3 flores estilizadas con animaciones fluidas en CSS.
- Modo Ramo Multicolor armónico y reactivo a 120Hz.
- 24 colores vibrantes que van rotando al hacer clic o presionar las flechas del teclado.
- Luciérnagas y mariposas de luz danzando sobre el follaje nocturno.
- Efectos de partículas de polvo estelar interactivos.
